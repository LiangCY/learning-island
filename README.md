# 学习探险岛 · Learning Island

让每一次练习，都成为一次小探险。面向小学生的本地学习应用，现已实现**口算练习**，后续可扩展识字、英语和更多学习内容。

不需要账号或数据库。练习记录、伙伴成长、收藏和小屋布置保存在当前浏览器，成绩单和涂色作品可以导出为 PNG。

## 本地运行

需要 **Node.js 18 或更新版本**。无需安装 npm 依赖，也不依赖外部字体或图片服务。

```bash
git clone https://github.com/LiangCY/learning-island.git
cd learning-island
npm start
```

打开 [http://localhost:4173](http://localhost:4173)。保持终端运行，按 `Ctrl+C` 停止；macOS 也可双击 `启动学习探险岛.command`。

默认仅监听 `127.0.0.1`。可用 `PORT=4174 npm start` 更换端口。**不同地址、端口和浏览器的记录互不相通**，日常使用请固定同一个地址。

## 已有功能

- **URL 路由**：页面切换同步到 `#/home`、`#/pets`、`#/games` 等地址，刷新后停留在当前页，支持浏览器前进、后退和收藏链接。小屋子页面、房间、画室及成绩单也能恢复；练习和成绩需要当前浏览器内已有的对应记录。
- **口算模块**：一至六年级难度，加减、乘除、综合与填空，支持小数、分数和百分数。年级表示难度档位，不保证与所有教材进度完全一致。
- **适合二年级**：100 以内加减；乘除口诀专项约四分之三为 1–9 乘法、四分之一为对应整除。综合练习仍可包含乘加、乘减。
- **简单练习**：20 / 30 / 60 题；每页 10 题的分站练习，或大字单题闯关；可暂停、跳过、检查，刷新后续练。
- **成绩与记录**：自动批改、实际用时、错题重练；每轮自动生成含成绩、用时、逐题结果的 PNG，保存在本地 `screenshots/`。
- **伙伴成长**：狐狸、兔子、熊猫、猫各自累计积分；答对 1 题获得 1 分，60 / 180 / 360 分依次升至四个阶段。每种伙伴拥有不同姿势、动作节奏和回应，支持未来形象预览。
- **伙伴小屋**：客厅、书房、户外花园、卧室四个场景；家具与伙伴可拖动或用方向键移动，各房间独立保存。物品按墙面、地面、地毯分区，拖动显示可放区域，越界回到原位。支持多件家具并存、逐件撤下和清空布置。
- **装扮和商店**：58 件好物（含 6 件入住礼物），48 件家具与配饰采用统一绘本插画，头饰、围巾、胸章可组合；日常 100–240、精选 280–840、典藏 900–3200 叶子币，支持试戴、房间试摆、房间专属商品、心愿单、按房间及档次筛选和收集手帐。旧购买按原成交价保留。
- **练习奖励**：80 入住币；每填答 1 题 +1，每轮填满 20 题额外 +10，每日首轮再 +10（按上海时区计算）。成长积分与叶子币分别计算。
- **卡片收集**：八套卡组，共 128 张卡；R / SR / SSR。抽卡机会可积攒，支持 2–10 张一起开包；每张保留获得机会时对应题量的概率。SSR 随题量由 15% 提升到 30%。
- **游戏乐园**：独立游戏大厅，按注册目录展示游戏；各游戏共享游戏币并独立保存进度，当前已接入涂色小画室。初始赠送 120 游戏币；每填答 1 题获得 2 币，交卷后自动到账，空白不奖励，历史填答也计入。游戏币与小屋叶子币独立，同一轮不会重复奖励。
- **涂色小画室**：28 张原创卡通线稿，按萌萌动物、奇妙旅行、甜甜日常、自然花园、进阶画板分类；基础画板 20–80 游戏币，8 张进阶画板 95–145 游戏币、每张 46–87 个独立色块，解锁后可反复创作。进阶画板含溪谷瀑布、海湾日落、星月宝石项链、花冠宝石首饰；已购买的旧版建筑画板和作品继续保留。支持 72 个纯色（含正红、深红等红色系）、8 种渐变，蜡笔 / 水彩 / 油画 / 彩铅，以及原画（排在首位） / 闪亮（细密金银闪粉） / 像素 / 柔彩 / 复古 / 糖果 / 反色 / 雾化，共 12 种画材与效果。各画材有独立的线条粗细、颜料质感和纹理：蜡笔粗线颗粒、水彩透明晕染与积色边、油画按色块转向的厚涂笔触与局部刷痕、彩铅按色块方向生成彩色短排线。保留色块交互，预览与 PNG 导出共用渲染。
- **作品展示墙与画框商店**：免费原木相框，另有奶油圆角、薄荷波点、莓果糖纸、鎏金画廊、星夜珍藏 5 款画框，售价 30–100 游戏币。买一次可反复装裱，客厅、书房、卧室各有 3 个展示位，与伙伴小屋同步。可换画、换框、撤下，更新作品自动同步，删除作品同时清理挂画。
- **我的作品**：自动保存画板草稿、80 步撤销重做、橡皮擦、作品命名、收藏、继续编辑、另存副本和 1440×1440 PNG 下载。手机提供底部随手调色盘，也可用 Tab + Enter 为色块填色。作品保存在当前浏览器，清理浏览器数据后无法恢复，请下载重要作品。
- **音效与动效**：可关闭音效；遵循系统减少动态效果设置。

## 数据与兼容

原项目名为 `math-island / 口算探险岛`，更名后保留已有本地存储键和服务识别标记，继续使用同一地址即可保留历史进度。仅提交应用源码及运行素材；个人练习截图、临时工作文件和环境变量文件不进入仓库。

小游戏存档继续使用原 `games` 存储键，旧画室数据在读取时兼容转换，并在下一次成功保存时升级为 v3 公共钱包和各游戏独立存档。旧画室链接和小屋挂画继续兼容。

## 素材说明

涂色画板使用原创 SVG 几何线稿，无外部素材请求。每个色块有稳定 ID；新增画板可扩展 `dist/coloring-boards.js`，后续修改已有画板应保留色块 ID，以兼容已保存作品。

原创伙伴图集由内置 imagegen 生成；本次物种差异化图集为 `dist/assets/companions/species-poses-v4.png`，完整提示词见 [生成记录](docs/asset-sources/companion-v4-prompt.txt)。渲染使用透明轮廓采样，源 PNG 像素保持不变。

卡组包含第三方作品的角色名称与形象，相关权利归各自权利人；本仓库不授予这些角色素材的商业使用许可。已记录的原始来源见 `docs/asset-sources/`。

房间与商品插画使用内置 image_gen 生成；素材保存在 `dist/assets/furniture/`，提示词见 `docs/asset-sources/cozy-world-prompts.txt`。伙伴名为狐狸阿橙、兔子朵朵、熊猫团团、猫咪星米，存档 ID 不变。
