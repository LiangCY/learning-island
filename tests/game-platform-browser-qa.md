# 游戏平台浏览器验收

日期：2026-10-04。使用独立测试地址 `http://127.0.0.1:4178`，购买、画作和挂画只写入该地址的测试存档；日常 `4173` 地址只读取大厅。

- 大厅展示公共钱包和注册游戏入口；点击进入后路由含 `game=coloring`。
- 初始 120 币，购买花园小猫画板后 100 币；涂一个色块、命名并保存作品，刷新恢复同一作品和 1/23 涂色进度。
- 编辑器可以返回大厅，余额仍为 100 币；销毁画室实例后大厅正常显示。
- 直接访问旧地址 `#/games?tab=gallery`，恢复作品集并规范化为带游戏 ID 的路由。
- 购买奶油圆角画框后余额 70 币，按钮变为已拥有；装框上墙后余额不变。
- 从展示墙进入伙伴小屋，能看到新存档中的命名画作和画框；小屋叶子币仍为独立的 80 币。
- 从小屋点游戏导航返回大厅；大厅与游戏之间浏览器后退、前进均正确恢复。
- 未知游戏 ID 返回大厅，提示游戏暂不可用。
- 桌面 1280px 和手机 390px 下页面宽度等于视口宽度，无横向溢出；手机标题按短句换行，入口按钮完整可用。
- 浏览器捕获的 warning/error 日志为空。
