# URL 路由浏览器验证

2026-10-04，Codex 内置浏览器。使用独立临时端口和测试截图目录，未修改日常使用地址的练习数据。

- 主要导航：图鉴、游戏、历史和错题页面切换后 URL 更新；刷新后地址及当前导航项保持一致。
- 伙伴小屋：切换卧室和伙伴成长页，刷新保留房间及子页面；浏览器后退、前进恢复相应页面。
- 作品展示墙：选择卧室后刷新，房间选择保持不变。
- 练习：开始 20 题，填写第一题，切到第二站后刷新，保留第二站并暂停计时；回第一站仍有已填答案。
- 成绩单：交卷后 URL 包含记录 ID；刷新和从历史页后退均显示同一份成绩。
- 涂色画室：购买测试画板后 URL 包含画板 ID；填色、命名后刷新，保留颜色及草稿名称。
- 编辑作品：收藏后 URL 包含作品 ID；再次填色并刷新仍显示新草稿和更新作品按钮；后退回商店、前进回同一作品。
- 失效链接：无未完成练习时回首页；不存在的成绩回历史；未知画板回商店；未知路由回首页。浏览器控制台无错误。

路由解析、重复导航和保存保护由 `router.test.mjs` 补充覆盖。
