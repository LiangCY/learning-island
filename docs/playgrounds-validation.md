## 设计参考与素材

自由园艺的布局思路参考 [Garden Life 官方介绍](https://www.nacongaming.com/en-GB/garden-life)，水族馆收藏与观赏节奏参考 [Chillquarium 商店介绍](https://store.steampowered.com/app/2276930/Chillquarium/)。本项目采用自己的免费初始场景、学习币和买断后复用机制，没有移植外部游戏素材。

四张场景/图集均通过内置 image_gen 原创生成，提示词记录在 `docs/asset-sources/playgrounds-prompts.json`。原始 PNG 保持不变，`scripts/prepare-playground-art.py` 仅分析透明连通区域并生成 CSS 裁切元数据，保留越过名义网格的鱼鳍、枝叶等细节。鱼缸、灯光、棋盘和动效由 CSS/SVG 渲染；伙伴头像复用项目已有素材。
